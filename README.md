# 🧶 Hoshii Store

A charming, responsive e-commerce website concept for **Hoshii Store**, a handmade crochet brand based in Algeria.

The website is designed to create a warm, playful shopping experience while showcasing handmade crochet products, delivery information, and custom orders.

## ✨ Features

* 🛍️ Product showcase with bestsellers
* 🛒 Interactive shopping cart
* 📦 Delivery information for all 69 wilayas
* 🔎 Searchable delivery-rate table
* 🧶 Custom order form
* 💌 Order submission via FormSubmit
* 📱 Fully responsive design
* ✨ Smooth animations and interactive UI
* 📧 Newsletter subscription section
* 💕 Testimonials section

The cart allows users to add products, view quantities and totals, remove items, and transfer their cart summary directly into the custom order form.

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* SVG
* Google Fonts
* FormSubmit

## 🎨 Design

The interface uses a soft, handmade-inspired visual identity with pastel colors, rounded components, crochet-inspired illustrations, subtle animations, and a cozy editorial aesthetic.

## 📦 Ordering

Customers can submit a custom order by providing:

* Full name
* Phone number
* Email
* Wilaya
* Item type
* Preferred colors
* Order details

The form is connected to FormSubmit, allowing submissions to be received by email without requiring a custom backend.
